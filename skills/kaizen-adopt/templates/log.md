# Kaizen log

Append-only, newest last. One entry per step that is done, dropped or blocked. Never
edit past entries; correct them with a new one.

Entry format:

```markdown
## <YYYY-MM-DD> — <done | dropped | blocked> — <step, as worded in the task list>
- list: <task-list path> › <parent item>
- owner: agent | user
- evidence: <file, message, decision, or what the user reported>
- notes: <anything the next agent needs; "none" if nothing>
```
