# Kaizen journal

A shared record of small steps and small improvements, written by you and by the
agent in the same simple format. One file per month (`YYYY-MM.md`), one heading per
day, one line per entry. Newest day at the bottom.

## Writing an entry

Find today's heading (or add it) and write a line that starts with a kind:

```markdown
## 2026-10-24 (Fri)
- done (you): Sent the application to Acme through their careers page
- done (agent): Drafted the Acme cover letter → applications/acme.md
- blocked (agent): Find the hiring manager's name — LinkedIn needs a login
- improved: A cover-letter template cut drafting time to about 20 minutes
- learned: Referrals get replies; cold applications mostly don't
- note: Stuck on the portfolio again; try 25-minute blocks tomorrow
- next: Pick the two projects the Acme letter should lead with
```

| Kind | Use it for |
| --- | --- |
| `done` | A step finished. Add `(you)` or `(agent)` |
| `dropped` | A step you decided not to do, with why |
| `blocked` | A step that can't move yet, with what blocks it |
| `improved` | Something that now works better than before: the heart of Kaizen |
| `learned` | Something you found out that changes how you'll work |
| `note` | Anything else worth remembering |
| `next` | The next small step you intend to take |

A line with no kind is fine too; it is read as a `note`. Add `→ path` or a link when
an entry has evidence. Don't edit old days to change history; add a new line instead.

The agent reads this journal in reviews to see what moved, what stalled and what
improved.
